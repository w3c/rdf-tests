This is a collection of individual
[EARL reports](https://www.w3.org/TR/EARL10-Schema/) for
test subjects claiming conformance to RDF 1.2 specifications.

To add your implementation, drop its EARL report as a Turtle file
in this directory and open a pull request.

The consolidated report is rolled up with the
[earl-report Ruby gem](https://rubygems.org/gems/earl-report) into
`index.html` and `earl.jsonld`. Both are generated by CI and published
to the `gh-pages` branch, so they are not checked in. To build them
locally, run the following from the root of the repository:

```sh
$ bundle install
$ bundle exec rake reports
```
